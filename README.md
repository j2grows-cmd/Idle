# ASCEND — Idle Incremental

Phase 1 foundation for a fully idle incremental game.

## Included

- Automatic energy production
- Four generator tiers
- Compounding generator costs
- Four upgrades
- Persistent local save
- Offline progression on return
- Live production telemetry
- Large-number formatting
- Premium responsive UI
- Reset-save control

## Run

Open `index.html` in a browser or serve the repository with GitHub Pages.

## Phase 1 progression

Energy → Generators → Upgrades → Offline Progress

Later phases can add research, prestige/Ascension, permanent progression, challenges, and additional production layers.
